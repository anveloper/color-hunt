# 컬러헌트

**오늘 본 색을 모아 9컷에 담는 작은 놀이.**

거리에서, 카페에서, 여행 중에 —
한 가지 색이 가득한 사진을 9개의 칸에 차곡차곡 모아
한 장의 이미지로 만들어보세요.

[color-hunt.run](https://color-hunt.run)

---

## 이렇게 놀아요

1. 한 가지 색이 가득한 사진을 찍거나 골라요.
2. 9칸 격자에 모아서 배치해요.
3. 한 장의 이미지로 저장해 SNS에 공유해요.

## 약속

- 사진은 어디로도 올라가지 않아요. 폰 안에서만 머물러요.
- 가입·로그인 같은 건 없어요. 들어와서 바로 시작.
