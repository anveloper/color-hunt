# 컬러헌트

![컬러헌트 OG](./public/og.png)

**친구들이랑 오늘의 색 하나를 정하고, 그 색이 많은 장면만 모아 9컷으로 엮는 작은 놀이.**

거리에서, 카페에서, 여행 중에  
괜히 눈에 들어오는 색 하나가 있잖아요.

컬러헌트는 그 색을 따라 사진을 모으고,  
한 장의 콜라주로 정리해서 바로 저장할 수 있게 만든 앱입니다.

웹([color-hunt.run](https://color-hunt.run))과 토스 미니앱(컬러헌트런)에서 같이 돌아갑니다.

![컬러헌트 로고](./public/logo.png)

## 이렇게 써요

1. 오늘의 색을 하나 정해요. 직접 고르거나 랜덤으로 뽑아요.
2. (선택) 기록을 켜요. 걸은 경로와 사진 찍은 지점이 남아요.
3. 그 색이 많이 담긴 장면을 찍거나 골라 격자를 채워요.
4. 기록을 끝내면 경로·시간·색을 사진 위에 자유롭게 배치할 수 있어요.
5. 비율을 골라 한 장으로 저장해요.

## 이런 점이 가벼워요

- 사진은 서버로 올라가지 않아요. 기기 안에서만 처리됩니다.
- 달린 경로도 기기 안에만 남아요. 어디에도 전송되지 않습니다.
- 위치를 허용하지 않아도 사진을 모으고 저장하는 건 그대로 할 수 있어요.
- 가입이나 로그인 없이 바로 시작할 수 있어요.
- 모바일에서 빠르게 놀고 저장하는 흐름에 맞춰져 있어요.

## 웹과 미니앱에서 뭐가 다른가요

| | 웹 | 토스 미니앱 |
|---|---|---|
| 사진 넣기 | 파일 선택 | 앨범에서 고르기 / 사진 찍기 |
| 저장 | 다운로드 | 기기에 바로 저장 |
| 위치 | 브라우저 권한 | 토스 권한 |

## 기술

React 19 · Vite 6 · TypeScript · Tailwind v4 · React Router 7
`@apps-in-toss/web-framework` · `@toss/tds-mobile` · `@use-gesture/react`
폰트는 쓰는 글자만 담은 Gaegu 서브셋을 셀프 호스팅합니다.

## 로컬 실행

```bash
pnpm install
pnpm run dev
```

| 명령 | 하는 일 |
|---|---|
| `pnpm dev` | 개발 서버 |
| `pnpm build` | 웹 배포용 빌드 |
| `pnpm lint` | 타입 검사 |
| `pnpm fonts` | 폰트 서브셋 재생성 |
| `pnpm build:ait` | 미니앱 번들(`.ait`) 빌드 |
| `pnpm deploy` | 미니앱 배포 |

> **한글 문구를 고쳤다면 `pnpm fonts`를 다시 돌려주세요.** 폰트 서브셋에 실제로 쓰는 글자만 들어 있어서, 새 글자를 추가하고 재생성하지 않으면 두부(□)로 보입니다.

## 토스 미니앱으로 빌드하기

```bash
pnpm run build:ait   # dist를 감싼 color-hunt-run.ait 생성
pnpm run deploy      # 앱인토스에 업로드
```

`apps-in-toss.config.ts`에 앱 이름(`color-hunt-run`), 브랜드 색, 권한(앨범·카메라·위치)이 선언돼 있습니다. 워크스페이스와 미니앱 ID는 레포에 없으니 [앱인토스 콘솔](https://apps-in-toss.toss.im)에서 확인하세요.

`.ait` 번들은 빌드 산출물이라 git에 올리지 않습니다.
