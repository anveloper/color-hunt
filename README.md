# 컬러헌트

![컬러헌트 OG](./public/og.png)

**친구들이랑 오늘의 색 하나를 정하고, 그 색이 많은 장면만 모아 9컷으로 엮는 작은 놀이.**

거리에서, 카페에서, 여행 중에  
괜히 눈에 들어오는 색 하나가 있잖아요.

컬러헌트는 그 색을 따라 사진을 모으고,  
한 장의 콜라주로 정리해서 바로 저장할 수 있게 만든 앱입니다.

[color-hunt.run](https://color-hunt.run)

![컬러헌트 로고](./public/logo.png)

## 이렇게 써요

1. 오늘의 색을 하나 정해요.
2. 그 색이 많이 담긴 장면을 찍거나 골라요.
3. 격자에 모아 배치하고 한 장으로 저장해요.

## 이런 점이 가벼워요

- 사진은 서버로 올라가지 않아요. 브라우저 안에서만 처리됩니다.
- 가입이나 로그인 없이 바로 시작할 수 있어요.
- 모바일에서 빠르게 놀고 저장하는 흐름에 맞춰져 있어요.

## 로컬 실행

```bash
pnpm install
pnpm run dev
```
